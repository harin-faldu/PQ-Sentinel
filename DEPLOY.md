# 🚀 QuantumVault CBOM — Quick Local Run Guide

1. **Start Docker Desktop** on your computer.
2. **Launch Platform**: Run `docker compose up --build` in the project root directory.
3. **Open Dashboard**: Navigate to [http://localhost:3000](http://localhost:3000) in your browser.
4. **Scan Codebase**: Click **"Scan Codebase"** and enter `sample_target` (or any local directory).
5. **View & Export**: Review live PQC risk analytics and click **"CycloneDX 1.6"** to download JSON/XML.
6. **Stop Platform**: Press `Ctrl + C` or run `docker compose down`.
